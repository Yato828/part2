# PART — realtime, Token X-Ray и расширение 1.3.0

Дата: 16 октября 2026. Все подключения относятся к **Solana mainnet**.

## Что изменено

**Token X-Ray.** Цитата об охвате largest accounts была пояснением источника. Реальные отказы возникали на `getTokenLargestAccounts`: в диагностике mainnet RPC вернул 429, PublicNode — 403. Добавлен общий для X-Ray и Bubble Map резервный источник RugCheck. Проверяются точный mint, owner-адреса, масштаб количества токенов и агрегация владельцев. UI показывает источник, время получения, число загруженных владельцев и частичное покрытие; не выдаёт время получения за неизвестное время holder-баланса. При неудачной повторной загрузке предыдущие данные остаются видны. Длинное описание охвата перенесено в раскрывающийся блок.

В живом проходе **20 владельцев BONK** загрузились через RugCheck и на сайте, и внутри установленного расширения, без ошибок этой загрузки. Это sampled largest-account owners, а не полный реестр всех держателей. Если RPC запрещает сканирование и у индексатора нет снимка, данные по конкретному mint всё ещё могут быть недоступны. Трансферные связи не выдумываются.

**Живой график.** Добавлена read-only WebSocket-подписка `accountSubscribe`. Цена извлекается из проверенного owner/discriminator/layout состояния пула. Поддержаны **Orca Whirlpools, Raydium CLMM и Meteora DLMM**. Изменения цены поступают по событию независимо от таймера индексированных OHLCV. Историческая сверка и объём остаются на отдельном интервале 5–30 секунд. В режиме источника без поддержанного spot-декодера UI прямо показывает Source candles only.

Новая цена обновляет заголовок и предварительную текущую свечу. Наблюдения объединяются в animation frame с сохранением всех полученных high/low. Исходные исторические свечи не перезаписываются этим слоем, отсутствующие бары не дорисовываются. Spot OHLC — наблюдение состояния AMM по времени получения браузером, не цена исполненной сделки. Объём берётся только из индексированного источника; при его отсутствии показано V pending source.

Добавлены processed/confirmed, пауза обоих каналов, Reconnect, ограниченный backoff/failover, очистка предварительного слоя при переподключении и остановка в скрытом/закрытом представлении. Запоздавшие сообщения предыдущих подписок/слотов не меняют актуальный поток. HTTP bootstrap сам по себе не включает индикатор LIVE: для этого нужно настоящее PubSub-сообщение. UI показывает slot, commitment, hostname узла и возраст последнего получения.

Для SOL-quoted токенов используется свежий поток SOL/USDC. Допущение **USDC ≈ USD** подписано; другие quote-mint без поддержанной конверсии не получают выдуманный USD-курс. Dedicated mainnet WSS можно задать в Settings → Connections. Этот URL хранится в браузере, поэтому нужен credential, рассчитанный на browser use; серверный OpenAI key туда вводить нельзя.

## Миллисекунды: что измерено

Нельзя превратить публичную сеть в гарантированный поток 1000 обновлений/сек опросом API каждую миллисекунду. Измерена фактическая обработка поступивших сообщений:

| Живой проход | Получено наблюдений за окно | Различных цен | Receipt → DOM commit |
|---|---:|---:|---:|
| Сайт | 5 | 4 | **1–9 мс** |
| Установленное расширение | 3 | 3 | **1–17 мс** |

Это локальная задержка после получения сообщения браузером. Она **не включает доставку от валидатора/RPC и последующую отрисовку canvas** и не является SLA. В этих же проходах публичные узлы присылали обновления с паузами в секунды. Гарантия «каждую 1 мс», самого первого входа или приоритета исполнения не заявляется. Для конкурентного sniping необходим подходящий выделенный источник; WSS endpoint теперь можно подключить без изменения кода. Processed-состояние может откатиться, поэтому оно подписано как предварительное.

## Расширение

Версия **1.3.0**, архив `public/part-ext.zip`, unpacked-сборка `dist-ext/`. Secure WSS разрешён в CSP сайта и расширения. Проверка выполнена в **настоящем установленном unpacked-расширении**, в отдельном временном профиле Chromium, а не только на странице popup.html через HTTP.

- Внутри `chrome-extension://` получили 500 исходных свечей и настоящие push-изменения Orca SOL/USDC; ошибок JavaScript нет, ширина popup — 400 px.
- Open desk открывает `popup.html?view=desk` в полной вкладке 1440 px. Закрытие popup не закрывает эту вкладку. Настройки синхронизируются между представлениями расширения; Graphite применился в обоих окнах.
- Открыты все 18 вторичных модулей. Проверены доступность настроек, поиска, возврата, торговой панели, holder-резерва и ссылки на сайт для кошелька.
- Размещённый ранее Astra API оказался недоступен. Добавлен явный выбор Hosted / Local development. Исправлен preflight локального Vite: CORS теперь обрабатывает API с точной проверкой Origin; wildcard для расширений не добавлялся.
- В Local development установленное расширение получило **реальный ответ gpt-6-astra** «PART supports Solana mainnet» и **HTTP 200 сценария** с шестью отдельными гипотетическими точками. Ключ остался на сервере.

Для локального Astra выбрать **Settings → Connections → Astra backend → Local development** при запущенном `npm run dev`. Точный локальный extension Origin зарегистрирован в `.env.local`; существующий ключ сохранён. Hosted-режим требует развёрнутого и настроенного сервера. Новая сборка сама по себе не публикует Vercel API или магазинное расширение. Уже установленный build нужно перезагрузить в `chrome://extensions`.

Новые проверки покрывают бинарные layouts, направление mint/quote и decimals, неправильный program/discriminator, пустые и повреждённые сообщения, старые subscription/slot, прекращение после unmount, backoff, различие bootstrap и push, неправильные endpoint-протоколы, предварительный OHLC без выдуманного объёма, owner-vs-account, чужой mint в holder-отчёте, RPC 403/429 и сохранение успешного снимка после сбоя. Browser fixtures проверяют остановку при Pause/hidden, возобновление, неизменность canvas/документа, fallback X-Ray, настройки, layout, вкладки, чат и безопасный HTML export. Реальные проходы выполнены отдельно.

Средства не переводились, mainnet wallet-подписи не выполнялись. Проверка реальной покупки с кошельком владельца не заменяется котировками или состояниями UI. Live deployment, X history, push/Telegram и hosting остаются за ранее описанными границами.

В одном промежуточном live-прогоне старый memecoin-пул вернул пустую выборку Flow. Проверка активных сделок перенесена на наблюдаемый SOL/USDC-пул, при сохранении исторического memecoin-теста свечей и строгих проверок hash/amount. Итоговый live-прогон прошёл полностью; пустая активность не подменялась выдуманными транзакциями.
