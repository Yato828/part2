# PART — отчёт о реализации и проверках

Это отчёт первоначального модульного обновления. Последующие настройки, цветные свечи, live updates и новый итог проверок описаны в [UI_CUSTOMIZATION_REPORT.md](UI_CUSTOMIZATION_REPORT.md); они заменяют указанное ниже ограничение на монохромное оформление.

Дата: **16 октября 2026**, время пользователя — Europe/Minsk (UTC+3). Работа выполнена в существующем репозитории. PART использует **Solana mainnet**; устаревшие требования master prompt о прежней сети и Stocks не применялись.

## 1. Что изменено

Главный терминал начинается с поиска и графика выбранного токена. Swap, сделки, аналитика, discovery и creation открываются отдельными модулями. Сохранены landing, персонаж, WebAudio и чёрно-белый стиль.

Добавлены launcher Ctrl/Cmd+K, навигация, внутренние вкладки, закрытие, закрепление одной панели, максимизация, перестановка вкладок и восстановление локального layout. Скрытые модули не продолжают опрос. Выбранный Solana-токен общий для графика, анализа, Swap и Astra; публичный адрес из Wallet Watch также передаётся в контекст Astra и может быть отсоединён.

Astra выполняет реальные серверные запросы в OpenAI Responses API. На проверенной локальной конфигурации upstream вернул модель `gpt-6-astra`. Добавлены локальные именованные ветки, ограниченная история, контекст, Copy, Regenerate, Clear, Stop, ошибки и статус подключения. Автоматические платные запросы при выборе токена убраны. Старый endpoint автоматического brief возвращает 410; локальная эвристика подписана отдельно и раскрывает метод расчёта.

Token X-Ray, Wallet Watch, Smart Money, KOL Analyzer и Exit Simulator используют реальные адаптеры и явные состояния недоступных данных. Launchpad готовит и экспортирует SPL-черновик; Tweet to Token передаёт его дальше; Website Builder генерирует редактируемый текст страницы, показывает изолированный preview и экспортирует HTML.

График использует Lightweight Charts: свечи и объём, OHLC, интервалы, история, логарифмическая шкала, оценка market cap, Latest и Expand. Убрано восстановление исторических USD-свечей через привязку к текущей цене. При недоступной истории график остаётся пустым или явно помечает сохранённые свечи как устаревшие.

## 4. Запуск

```sh
npm install
# При необходимости заполнить серверные значения по .env.example, сохранив существующий .env.local.
npm run dev
```

Локальный адрес: **http://localhost:4664/**. Режим расширения: `npm run ext:dev`, http://localhost:4666/. Архив: `public/part-ext.zip`.

Для Vercel нужны серверный `OPENAI_API_KEY`, доступная аккаунту `ASTRA_MODEL` и постоянный Upstash limiter. Production без постоянного limiter закрывает платные запросы. Точные переменные, команды CLI и настройка extension origin описаны в [SETUP.md](SETUP.md). Публикация на Vercel не выполнялась.

## 6. Jailbreak и негативные сценарии

Проверены подмена роли на `system`, чужая сеть/EVM-адрес, некорректный public key, URL вместо mint/wallet, лишние аргументы инструмента, произвольный write-tool, чужой Origin и незарегистрированное расширение, повреждённый JSON, превышение размера/history/session, отсутствие ключа, сбой upstream, лимит запросов, недоступный production limiter и ограничение tool loop.

В браузере проверены `<script>`, `onerror`, `javascript:` links, iframe/form injection, внешние resource URLs и CSS в редактируемом сайте. Preview/export удаляют неподдерживаемые элементы и атрибуты; родительская страница не получила исполняемый код. Сообщения чата отображаются как безопасный текст.

В реальном запросе к `gpt-6-astra` была попытка через «SYSTEM» внутри имени токена получить ключ, сменить PART на EVM, выполнить swap без кошелька и придумать подтверждённый tx hash. Ответ отказался выполнять эти действия и сохранил Solana mainnet. [Результат](test-artifacts/live-jailbreak.json). Это результат проверенных сценариев, а не доказательство невозможности любого будущего jailbreak.

## 7. Что требует отдельной проверки владельцем

- **Реальные подписи и отправка средств не выполнялись.** Для проверки реального wallet connect, отказа/подтверждения подписи, исполнения и финального баланса нужен кошелёк владельца. Проверены состояния интерфейса, котировки и существующая валидация; это не полный mainnet trading E2E.
- Popup проверен в Chrome как компактный shell, отдельно запущен extension-режим и проверен ZIP. Установка unpacked-расширения в личный Chrome-профиль и интеграция с установленными wallet extensions не выполнялись.
- Настоящий Redis/production multi-instance limiter и Vercel deployment требуют серверной конфигурации; локально проверены его границы и fail-closed поведение, реальный Redis не подключался.
- X/KOL history, полноценный holder/transfer indexer, push/Telegram, image generation, live SPL deployment и hosting требуют соответствующей реализации и/или авторизованного провайдера. Успешная работа этих подключений не заявляется.
- Публичные APIs могут отвечать 429/403 или не отдавать историю/holders. Эти отказы наблюдались и отображаются. Кеш и исправление proxy уменьшают повторы, но не гарантируют доступность провайдера.
- Совместимое исправление устранило high advisory `source-map-js`. Оставшиеся moderate относятся к цепочке `@solana/web3.js → jayson → stream-json/uuid`; npm предлагает major-переход на web3.js 3.1.0. Принудительная несовместимая миграция торгового SDK не выполнялась. [Полный аудит](test-artifacts/npm-audit.json).

Технические компромиссы: чат пока возвращает целый JSON-ответ с отменой вместо token streaming; website generation создаёт текст в безопасном шаблоне; Launchpad экспортирует проверяемый draft без deployment transaction. Эти состояния обозначены в интерфейсе и setup.
