# PART — настройки интерфейса и живой график

Следующее обновление WebSocket, Token X-Ray и установленного расширения описано в [REALTIME_REPORT.md](REALTIME_REPORT.md). Оно добавляет поток цен независимо от прежнего таймера исторических свечей.

Проверено 16 октября 2026 года. Проект использует **Solana mainnet**. Изменения внесены в существующий терминал; landing, персонаж, кошельки и модульная структура сохранены. Новое требование пользователя о цветах заменяет прежнее ограничение на монохромный терминал.

## Что доступно

- **Settings → Appearance:** Midnight / Graphite / Black, пять акцентов и собственный цвет, плотность, размер текста, подписи навигации, цветные логотипы, уменьшение анимации. Изменения применяются сразу и сохраняются локально.
- **Chart & live data:** зелёные/красные свечи по умолчанию; собственные цвета роста и падения, альтернативная синяя/оранжевая палитра. Настраиваются объём, сетка, crosshair, полые свечи, статистика, начальный таймфрейм, число видимых свечей и следование за последними барами.
- **Навигация:** читаемые названия групп, список инструментов активной группы, прямой вход в Settings. Launcher и Ctrl/Cmd+K сохранены. На телефоне остаётся компактная панель.
- **Живые свечи:** обновление без перезагрузки страницы и без пересоздания chart canvas, по умолчанию раз в 5 секунд. Доступны 5/10/15/30 секунд, пауза и ручной Refresh. Новая свеча добавляется, текущая обновляется, исправления исторических данных принимаются от источника. При просмотре истории позиция сохраняется. Latest возвращает к последним свечам, Fit показывает загруженную историю.
- **Features & Astra:** независимые переключатели Flow, holder research и creation tools. Отключённые инструменты недоступны в launcher и не продолжают загружаться в закреплённой панели.
- **Connections / Layout & data:** проверка конфигурации API, сброс оформления, сброс layout и очистка локальных данных модулей.

Обновление графика — опрос публичного источника, а не биржевой поток каждого тика. При недоступности API сохраняется явная отметка об устаревших данных, используется пауза между повторными попытками. Исторические свечи не дорисовываются. Невидимый/закрытый график не продолжает опрос.

## Как включить линию Astra

**Settings → Features & Astra → Enable Astra chart scenarios**, затем выбрать Solana-токен и нажать **Generate scenario** под графиком. Само включение функции не отправляет платный запрос.

Работает реальный серверный OpenAI Responses API. В живой проверке ответила модель **gpt-6-astra**. Сервер сам проверяет выбранный Solana-пул, получает свежие исходные свечи и запрашивает структурированный ответ. Нужно не менее 20 реальных свечей. Подставленные клиентом цены, промпты и сообщения не используются.

Результат — отдельная пунктирная линия на 6 или 12 интервалов с моделью, источником, временем и допущениями. Это **гипотетическая иллюстрация без подтверждённой точности прогноза**. Реальные свечи продолжают обновляться независимо. Доступны Regenerate, Clear и Stop; при смене токена, пула или интервала запрос отменяется и слой очищается. Сценарий не может запускать торговые инструменты или подписывать транзакции.

Функция использует существующий серверный `OPENAI_API_KEY`, модель и лимиты Astra. Для production, как и чату, нужен постоянный Upstash limiter. В браузер ключ не попадает. Развёртывание на Vercel в этой задаче не выполнялось.

Настройки на мобильном не создают горизонтальную прокрутку документа. HTML preview остаётся изолированным, без исполняемых скриптов.

| Возможность | Наблюдение |

| AI-линия | HTTP 200, `gpt-6-astra`, 6 будущих точек, источник GeckoTerminal. До и после генерации **500 реальных свечей**; гипотетические точки не добавлялись к ним |
| Markets / Pulse / New Tokens / Trends | Вкладки открываются, работают реальные запросы Solana discovery; отсутствие строк таблицы в heatmap не означает отсутствие данных |
| Flow / X-Ray / holders | Flow вернул реальные сделки. В X-Ray доступны данные и ссылки; holder RPC в живом проходе отказал с 403. Интерфейс показывает недоступность, а не выдуманную holder distribution |
| Wallet Watch / Smart Money / Blocks | Проверены навигация, обработка ответов/ошибок и прежние детерминированные сценарии; доступность публичного RPC зависит от провайдера |

Реальные wallet-подписи, отправка средств и mainnet swap **не выполнялись**. Установка расширения в личный Chrome-профиль не выполнялась. Live SPL deployment, социальный индексатор, push/Telegram, AI images и hosting остаются явно отключёнными/неподключёнными согласно предыдущему объёму реализации. Это не проверка их успешной интеграции.

Оставшиеся moderate advisories относятся к цепочке `@solana/web3.js → jayson → stream-json/uuid`. Принудительное несовместимое обновление торгового SDK не выполнялось. Публичные источники могут ограничивать запросы; стабильная мгновенная доставка всех тиков не заявляется.

## Негативные проверки и jailbreak

Повторно прошли проверки подмены system-role, чужой сети, неверного адреса/URL, опасных HTML/JS/CSS, чужого Origin, размера запроса, history/session, отсутствия ключа, ошибок upstream, лимитов и запрета write-tools. Новые проверки покрывают CSS-инъекцию через сохранённые цвета, неподдерживаемые интервалы (`toString`, `__proto__`), подставленные клиентские цены/инструкции, чужой пул, пустую историю, бесконечные/чрезмерные/неполные AI-точки и попытку модели вызвать `sign_transaction` вместо линии. Такие запросы/ответы отклоняются; фальшивого сценария на замену нет.

AI-ответ отображается текстом, точки валидируются отдельно, а реальные свечи не изменяются. Ранее выполненный живой jailbreak чата сохранён в [live-jailbreak.json](test-artifacts/live-jailbreak.json). Перечень проверок не означает доказательства невозможности любого будущего jailbreak.

## Запуск и артефакты

```sh
npm install
npm run dev
# http://localhost:4664/

# Обновить расширение и затем web-артефакт со свежим download ZIP:
npm run ext:zip
npm run build
```

Не перезаписывайте существующий `.env.local`; параметры описаны в [SETUP.md](SETUP.md). Тестовый архив расширения — `public/part-ext.zip`. HTML-отчёт браузерного набора — `playwright-report/index.html`.

Живые отчёты и снимки сохранены в [test-artifacts/customization](test-artifacts/customization/): график, Settings, мобильный экран, сценарий, котировки, генерация и проверка артефактов. Автоматические тесты с fixtures и живые проходы описаны раздельно; оплаченные запросы OpenAI делались только в живых проходах.
